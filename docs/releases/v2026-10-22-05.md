## DIRECT分流调查未关闭

本轮没有改变路由、DNS、策略组或TLS政策。真实YAML编译器→隔离mixed→SOCKS业务载荷的9项合成回归通过，包含DIRECT、代理、REJECT、DOMAIN／SUFFIX、first-match与自定义v3 RULE-SET。DIRECT目标收到64字节且AnyTLS业务流／字节全零，代理正控明确出现业务流；故障变异能检测到错误代理。

这些证据只证明项目Mac合成mixed路径，不证明用户报错安装、实际生效配置、规则集内容或TUN物理出口正常。用户“应直连却代理”的具体原因仍未确认，需要报错机器和一个应直连域名／目标IP，不发送令牌或完整订阅。本版不是该未知问题的修复声明。

## 安装

```bash
curl -fsS https://raw.githubusercontent.com/NiuStar/anytls-core/main/get.sh | bash
```

公开安装器默认取最新稳定Release；在Mac本机普通用户终端执行，不加sudo。安装保留配置与应用密码、备份程序、核验后切换WebUI，不启停或重载VPN。需要系统授权时仅在本机终端完成，聊天和网页不接收系统密码。
