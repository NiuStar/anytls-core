# v2026-10-30-02 — Web控制台后台托管与更新后自动重启

## 本次变更

- 新增普通用户 `webui install-agent [--listen 原地址 --port 原端口]` 和 `webui agent-status`。使用当前登录用户的 LaunchAgent 后台运行与 KeepAlive；保留显式监听参数、配置、节点选择和密码，不使用 sudo，不接管已占用端口或停止旧进程。
- 受管控制台更新时，等待安装子进程退出并独立核对磁盘版本，再重新确认当前 PID、任务、plist、程序参数和用户身份；只有全部通过才在响应序列化及 Flush 后请求排空并结束旧控制台，由 launchd 拉起磁盘新版。
- 安装失败、版本不确定、身份核验失败或响应写入失败不自动退出。手动或 nohup 控制台没有受管退出能力，继续提示手动重启。
- 浏览器有界等待恢复；旧 cookie 的401不是新版成功。重新登录后，只有内存版本精确等于目标版本才确认完成。不自动重复安装，不重载 VPN，不更新特权助手。
- 安装生命周期警告直接进入静态页面，避免依赖易失效的 HTML 前缀替换。

## 首次启用

**旧控制台不会因为磁盘升级而自动获得这段新逻辑。首次需更新程序，并在没有安装或其他操作进行时退出旧 Web 控制台，再一次性启用托管。不要停止 VPN，不用 pkill。**

在 Mac 本机用原入口安装，不对整条命令加 sudo：

```sh
curl -fsS https://raw.githubusercontent.com/NiuStar/anytls-core/main/get.sh | bash
```

该原安装入口可能按既有流程请求系统授权更新配套特权助手；这不属于新增 WebUI 自动重启机制。普通网页更新／`anytls update` 本身不更新 root helper。本版不自动启用托管或重载已有 VPN。

先确认旧 WebUI 已空闲退出且端口空闲，再以普通 GUI 登录用户执行（以下为本机默认；LAN 用户须保留原 listen/port）：

```sh
~/.anytls/anytls-macos webui install-agent --listen 127.0.0.1 --port 18089
~/.anytls/anytls-macos webui agent-status --listen 127.0.0.1 --port 18089
```

核对 `restartManaged:true`，打开原控制台地址并登录。之后从这个受管控制台执行的网页更新才支持自动重启。HTTP 无TLS，LAN访问有明文凭据风险；不自动将loopback扩大到LAN。

## 安装期间禁止外部卸载或强杀

**`launchctl bootout` 不是原子安全停止。真实 Mac 上即使 `ExitTimeOut=0`，它仍可立即终止控制台和安装子进程。仅在确认空闲且避免并发操作时，才可按 `docs/webui-autorestart.md` 的精确任务指引卸载。** 不承诺强制卸载、强杀、崩溃或关机时安装完整；完成状态不明时先查磁盘版本、配置与备份，不能盲目重复安装。

应用自身的更新重启和普通 SIGTERM 会关闭新请求准入，等待既有 handler 和其安装子进程；排空超时不以强杀结束。保留 KeepAlive 意味着单发 SIGTERM 会重新拉起。程序不新增 agent-stop 或 disable/enable 状态机制。
