# v2026-11-07-02 — AnyTLS 0.4.1 双架构菜单栏 App

## 下载与兼容性

新增 Intel 原生菜单栏一体 App，最低 macOS 13，继续提供 Apple Silicon 版：

- Intel Mac（x86_64）：`anytls-core-v2026-11-07-02-menubar-darwin-amd64.zip`
- Apple Silicon（arm64）：`anytls-core-v2026-11-07-02-menubar-darwin-arm64.zip`

两包均为 App 0.4.1 / build `0.4.1.20261107.1`，携带各自同架构核心与固定助手能力，不需要用户安装 Go／Python。解压、拖入「应用程序」并打开，主动选择「安装／更新组件…」，按需接受 macOS 原生管理员授权。首次安装不启动 VPN。两包为各自原生架构，不是 universal，不把交叉编译或 Rosetta 运行当作 Intel 原生验收。

签名仍是 **ad-hoc，未经 Developer ID 签名或 Apple 公证**，不保证 Gatekeeper 放行。保留既有 bundle identity，不新增登录窗口、不查询钥匙串。后端认证、CSRF、helper 身份及系统授权保持不变。

## 实现与发行门禁

- 构建器严格匹配宿主、UI、核心架构；Intel 对应 `amd64` 发行名与 `x86_64` Mach-O，Apple Silicon 对应 `arm64`。
- 运行时按 App 编译架构验证内嵌 manifest，混装另一架构核心必须拒绝，不能通过将支持列表放宽为两者来绕过。
- Apple Silicon 与 Intel runner 都执行真实 App 构建和五组 Swift fixture；Intel App 步骤不再跳过。原生执行、签名、解压后验包须有对应任务回执。
- 每个架构分别验证 CLI、对应源码与 App 的绑定；公开附件为七个归档加 `SHA256SUMS`，其中包含两个 App ZIP。源码、依赖与许可证随对应源码包提供。
- 无登录窗口、后台不抢前台、250ms 配套流量采样及正常退出前安全 STOP 逻辑不变；UNKNOWN 不自动重放。

## 旧版升级

先用旧 App 正常退出并停止 VPN，再替换为同芯片 App。打开新 App 后主动执行「安装／更新组件…」，不能只换 App 就假定核心已更新。规范旧布局保留配置、选择、密码及相对资源；未知布局／身份／事务保持 HOLD。更新后 VPN 保持停止，由用户主动点击「恢复 VPN…」。不自动跨架构迁移已安装组件。
