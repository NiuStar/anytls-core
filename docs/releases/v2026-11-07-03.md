# v2026-11-07-03 — AnyTLS 0.4.2 安装更新反馈修复

App 0.4.2 / build `0.4.2.20261107.1`；保留 macOS 13+ 的 Apple Silicon 与 Intel 独立一体 App。

## 修复

- 修复点击「安装／更新组件…」并确认后，被保留的已结束核心重载记录一律阻断的问题。仅在完整原始回执、父级确认或既有对账证明、操作与配置路径绑定、文件身份和权限均通过验证时，才识别为已结束；不删除记录，不重放重载或 STOP。真正未完成、损坏、未知或不支持的事务继续 HOLD。
- 对大小写不敏感文件系统上的保留文件别名采取失败关闭，避免将 `Pending.json` 当作普通附件。安装提交继续在共享锁下重新检查，预检不等于提交授权。
- 更新失败在菜单与提示中显示固定、非敏感原因，包括 `CORE_RELOAD_PENDING`；不会回显配置、凭据或原始日志。异步失败不激活窗口或弹框。
- 操作进行中或结果未知时禁用安装入口；过期菜单动作也显示明确拒绝，不再静默返回。

## 使用与边界

正常退出旧 App 并停止 VPN，再替换同芯片 App；打开后主动选择「安装／更新组件…」，按需接受系统管理员授权。更新保留配置、选择和密码，VPN 不自动恢复；用户主动选择「恢复 VPN…」。发布和测试不授权替换用户运行中的组件或启停 VPN。

签名仍为 ad-hoc，未经 Developer ID 签名或 Apple 公证，不保证 Gatekeeper 放行。CLI、双架构 App、对应源码和许可证均应与精确发行提交绑定。此前 0.4.1 的结果不能代替本版最终提交测试。
