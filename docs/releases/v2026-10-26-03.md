# v2026-10-26-03 — GEOIP CN

## 本版内容

- 原生支持 `GEOIP,CN,target` 与 `GEOIP,CN,target,no-resolve`，target 可为 AnyTLS 节点、select 组、DIRECT 或 REJECT；规则有序、第一条命中生效。支持 Clash 导入、原生配置、保存／导出和私有运行快照；真实连接记录保留 GEOIP/CN 种类与实际出口，不猜测命中子网或连接成功。
- 仅接受精确 `CN`；不将 `gcn`、`cn` 或其他国家规范为 CN。其他国家在 Clash 导入预览按既有不支持项跳过并提示，原生配置拒绝。用户须自行显式添加所需规则，本次发布不更改既有正式规则。
- 内嵌 gaoyifan/china-operator-ip 完整 CN 快照：6525 条 IPv4、3489 条 IPv6，2026-10-26；来源是可信国内 BGP 分类＋未宣告 RIR-CN 登记兜底，不保证物理所在地或商业数据库完整度。精确上游提交、原始 SHA、MIT 完整许可及更新方式在 `assets/geoip/SOURCE.json`、`assets/geoip/LICENSE` 与第三方说明中。运行时不联网取数据，也不自动更新或过期。
- 保留固定 sing-box v1.14.3／Go1.27.3 和既有依赖、SDK、补丁、构建 wrapper、打包器；使用 SDK 原生 `ip_cidr`，不恢复已移除的旧 GeoIP 数据库选项。保留02版 sticky 祖先守卫兼容及01版记录归属／单次启动构造等既有行为。

## 解析与出口边界（必须阅读）

无 `no-resolve` 时，仅流量到达该规则位置才主动解析，沿用 secure-dns（1.1.1.1 DoH，经 anytls-out）与 prefer_ipv4；此前已命中的规则不会因 GEOIP 主动解析。此模式会为原本无 DNS block 的 mixed 配置加入 DNS 服务，并启用 DNS hijack/reverse_mapping；较早 DOMAIN→DIRECT 的实际拨号仍可能依赖该 DNS 服务。

域名解析结果中任一地址属于内置 CN 集合即命中；实际拨号仍可能使用完整地址列表，因此命中 `GEOIP,CN` 不保证最终连接 IP 属于 CN。

`no-resolve` 不新增解析动作或 DNS block，仅匹配已有目标 IP（含此前已解析结果）。非 GEOIP 配置保持原有 DNS／规则编译结果。
