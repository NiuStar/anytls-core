## 一期实际提供什么

`dns_schema:1` 绑定同次运行的已加载 DNS 策略、实际注册 transport 与运行 manifest。核心在 Start 后标记 LOADED，保留最近最多64条实际 HTTPS Exchange／ExchangeAsync 完成，并记录 httptrace GotConn 连接取得计数（新建／复用／空闲）。这是已加载策略加有限传输完成证据，不是完整 query／capture／cache 账本，不保证所有业务 DNS 都被记录。

观测只对新暂存且已绑定启动 operation／epoch 的嵌入式服务启用；普通 CLI／Check 不启用，既有服务 argv 和进程不迁移。发送由有界自有 worker 执行，错误不向转发传播；序号、GAP、丢弃计数及 STALE 显式呈现。认证控制台 API／页面按 instance／generation／manifest 读取，绑定不匹配不回退到 latest。助手复制独立启动绑定，按现有进程身份、注册和快照守卫验证 push，生命周期替换／停止会使绑定失效；助手重启不从磁盘接管旧 latest。

缓存读取并不是持续存活或持续注册证明。独立于 helper 生命周期／push 的外部注册变化仅在下一次 push 身份认证时检测。旧助手错误映射为 UNAVAILABLE，不承诺正向识别 UNSUPPORTED。

公开投影不含查询名、客户端、答案、原始错误、任意主机／路径／标签或凭据。固定安全 endpoint／SNI 投影和配置端口不是独立线缆观测；configured detour 仅 CONFIGURED_ONLY。缓存命中、coalesced、HTTP status、新 TLS 握手、实际叶证书、具体 detour 与 Router-query join 均 NOT_OBSERVED；成功完成及 STRICT_CONFIGURED 不可解释为这些额外证明。

## DNS stream 修复及不变合同

新增经 wrapper 认证的 sing-box v1.14.3 DNS stream CachedConn 所有权补丁，不升级 SDK。构造阶段同步接管连续具体 CachedConn 层的缓存，有限 replay buffer 的读／释放互斥，网络读取不持锁；Close 唤醒底层连接后清理缓存，幂等保留首次 Close 结果，避免异步交换与旧缓存所有者重复读取／释放。适用于 route hijack、旧 DNS outbound 和 Linux resolved stream 路径；Linux resolved 在本期仅源码审查，不冒称 Darwin 执行覆盖了 Linux 运行时。

不透明包装隐藏的 CachedConn 不在具体顶层接管边界内；不是 sing 通用 CachedConn 全局修复。不改变 UDP、重试、超时、TLS、DNS 错误／取消映射、缓存政策或非 DNS 转发。补丁身份、原始模块及结果摘要进入 wrapper 收据，打包和源码安装器要求对应材料。既有严格 DoH／TLS、无明文回退、默认逐连接安全换族与同规则／同具体出口／业务载荷前 ACK 门保持，不宣称新增 WAN 提速。

## 更新及用户自有操作

普通 CLI／网页 update 只替换用户程序，不替换 root 助手，也不自动重载 VPN。`control_helper.go` 的 start 使用助手自身 `self`，`service.go` 再从该程序暂存运行核心；只升级用户程序不能证明旧助手下一次启动了新核心。

用户要在正式 VPN 中获得本版新观测，须在 Mac 本机走既有完整安装／系统授权更新配套助手，再按自己的维护安排显式重连，分别核对用户程序、助手、VPN 身份和业务结果。发布本身不安装、不更新助手、不启停 VPN／TUN，不改正式 DNS、节点、规则或凭据。默认 WebUI `0.0.0.0:18089`／mixed `0.0.0.0:11080` 和权限边界不变；HTTP 不加密会话、mixed 无入站认证，仍须限制网络暴露。

本版不宣称 Google／Chrome Web Store、目标站点、所有 IPv6 故障、既有 status 挂起／Shutdown 错误或正式 TUN 已修复；不支持路径保持 UNKNOWN。更细边界见 [DNS 运行证据](../dns-runtime-evidence.md)。实现阶段 stream 文档保留其当时的本地候选措辞，不作为本版永久禁止发布或安装授权。
