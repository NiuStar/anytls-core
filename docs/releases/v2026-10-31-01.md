# v2026-10-31-01 — 显式启用的 DoH 聚合诊断

## 变更

- 新增 `--dns-metrics`，仅用于 `embedded_core` 构建的前台 `run`，默认关闭。每次运行独占固定容量聚合器；省略或显式关闭时注册原始 HTTPS transport，不在 DNS exchange 路径增加观测包装、计时、错误分类或 httptrace 分配。
- 显式启用时，观测真实 SDK HTTPS DoH 上游操作完成：同步 Exchange 或异步回调各记一次 `upstream_exchange`，不是每个内部 HTTP 尝试或每个客户端查询。提供 A／AAAA／其他类型、受限结果类别、耗时桶及最大耗时，以及 GotConn 连接取得、新建、复用与空闲复用计数；连接事件不等于唯一 socket 或查询数。
- 进入嵌入式 engine run 后，在其返回时向 stderr 尝试写一次 `event: dns_metrics_final` JSON 行；不新增 stdout 输出、不落盘、不记录查询名、payload、IP、URL、原始错误、配置或凭据。配置准备失败或参数拒绝不输出汇总，写失败不替换主错误／退出码。强杀、崩溃或不可写 stderr 不保证有汇总；同步 stderr 仍需持续可写。
- 这是完成后的一次性诊断，不是 WebUI 实时监控；没有周期采样、HTTP metrics endpoint、持久化开关或自动给正式 daemon 启用。保留取消、原响应／错误和既有 transport 生命周期接口。

## 观测盲区与成本

- `hijacked`、`cache_hit`、`coalesced`、`http_status` 明确为 `NOT_OBSERVED`，不是零命中、零合并或零错误。上游与连接两部分各自一致、分开采样，不承诺跨部分一一对应；HTTP 重试或拨号失败也会改变事件对应关系。
- SDK 对真实 HTTP 503 返回无可靠 typed status 的错误，因此聚合为 `OtherError`，不解析原始错误文本、不将保留的 HTTP503 类别伪装为已观测。TLSFailure 只依据可识别类型；错误密码等普通错误不猜作 TLS 故障。
- 五轮真实 SDK transport 的确定性拨号失败成对 benchmark：同步关闭／开启中位 3469／3938 ns/op，开启增加 469 ns、352 B、9 allocs/op；异步 4906／5402 ns/op，增加 496 ns、416 B、10 allocs/op。这是包含请求构造、trace 及 SDK 异步 goroutine 的局部成本，不是 WAN／TLS／DNS 端到端 RTT 或提速证明。
- completion helper 单独测量为 0 B/op、0 allocs/op，不能冒充实际启用后的 runtime transport 零分配。本版不宣称 DNS 加速、全指标改善、程序瘦身或 Google IPv6 故障已修复。

## 使用与保持边界

flags 放在命令前；仅在用户自行安排的前台运行中显式启用，例如：

```sh
anytls --config /path/to/private.yaml --node example --dns-metrics run
```

退出后逐行筛选 stderr 中的 `dns_metrics_final`；stderr 仍可包含既有日志与主错误，不能当作单个 JSON 文档。`check`／`list`／`select` 不接受开启此 flag，非嵌入构建也明确拒绝。完整输出契约见 [CLI 说明](../doh-performance-report.md)。

TLS 校验、AnyTLS detour、进入 TUN 的 UDP／TCP 53 严格 DoH 规则、DNS 缓存／TTL、重试／超时及路由优先级不变；不增加备用解析器、不退回明文、不延长 TTL。SDK／依赖、补丁、正式 wrapper 的认证门、打包器与发行工作流保持；wrapper 仅增加已认证 Go test JSON 输出的测试计数支持。既有 status 挂起／Shutdown 错误、Google IPv6 与 Intel 现场问题不在本版修复。

## 更新

在 Mac 本机使用原安装入口，不对整条命令加 sudo：

```sh
curl -fsS https://raw.githubusercontent.com/NiuStar/anytls-core/main/get.sh | bash
```

原安装入口可能按既有流程请求本机授权更新配套助手；普通网页更新／`anytls update` 不替换 root helper，也不重载 VPN。已有用户级托管控制台仍按原校验／排空流程自动重启并认证读回目标内存版本，可能需重新登录；不能把 401 当成功。

首次托管仍按 v2026-10-30-03 流程：空闲退出旧 WebUI，以普通 GUI 登录用户一次性执行，LAN 用户保留原监听地址／端口；旧内存或 nohup 不自动迁移。

```sh
~/.anytls/anytls-macos webui install-agent --listen 127.0.0.1 --port 18089
~/.anytls/anytls-macos webui agent-status --listen 127.0.0.1 --port 18089
```

安装期间禁止外部 bootout／强杀；ExitTimeOut=0 不保证外部卸载安全。本次发布不执行目标机安装、助手替换、LaunchAgent 迁移或 VPN／TUN 启停，不自动给正式服务打开诊断。只发行 macOS ARM64／Intel；校验和不等于 Apple 签名或公证。详见 [托管说明](../webui-autorestart.md)。
