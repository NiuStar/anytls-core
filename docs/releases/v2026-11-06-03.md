# v2026-11-06-03：自动检查更新与真实区间流量折线

## 变更

- 登录并打开管理台后自动检查更新；检查成功后每小时检查一次，失败后约 15 分钟重试。仅在已登录、页面可见且在线时执行；隐藏或离线时暂停，关闭页面后不再检查，切换页面不会额外触发检查。
- 自动检查与手动检查共用在途请求，调试操作保留独立权限边界。检查失败保留上次可信结果，未知状态不会显示为绿色“已是最新版本”。自动检查只查询版本，不自动下载、安装、操作助手或重启 VPN。
- 流量历史按真实采样区间的平均速率绘制折线，采样点位于各区间时间中点，相邻有效区间正常连线；真实缺测处断开，不补造流量或把缺测填成零。
- 单个样本和真实零流量保持可见；峰值、坐标与提示使用一致的精确数值。实时未完成区间与累计历史区分显示，不把当前速率伪装成第二条历史数据流。
- 实际网络丢包率仍为“未测量”；HTTPS 探测成功率、延迟或图表连续性均不代表真实丢包测量。

## 兼容与安装

本版仅更新管理台前端及其回归测试，不改变 DNS、TLS 校验、路由、安装器、IPv4-only/显式双栈策略或 VPN 生命周期。

公开发行验收完成后，在 Mac 本机以普通用户执行（不要给整条命令加 sudo）：

```sh
curl -fsS https://raw.githubusercontent.com/NiuStar/anytls-core/main/get.sh | bash
```

保留现有节点、配置与应用密码。完整安装器及其助手安装沿用原策略：原 VPN 为 RUNNING 时，安装成功后默认单次重连；原 VPN 为 STOPPED 时不自动启动。UNKNOWN/pending 不通过盲重试解除。此入口不同于旧版管理台内的程序文件替换提示，不能据该提示推断完整安装器永不重连。本次发布任务不执行安装器、不远程更新正式助手、不重启 VPN。
