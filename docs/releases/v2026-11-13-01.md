核心与预定标签：`v2026-11-13-01`，分支 `release/0.5.6`；从已发布 0.5.5 提交 `f836e2c102637d4392ecdd4e54ce67eaf24ebf4d` 导入已冻结审核的菜单栏 UX 改动。面向 macOS 13+，Apple Silicon arm64 与 Intel x86_64（发行名 amd64）分别提供原生包。当前是本地发布候选准备，尚未发布，二进制未发布；最终 hosted CI、构建与公开下载资格仍待验证。

## UX 与诊断

- 菜单打开时及时呈现操作进度与结果，保留动作／事务身份及 UNKNOWN 的失败关闭语义；未知结果不解锁、不自动重放。
- 失败解释与可复制摘要仅使用固定白名单原因、受校验的操作 ID 和安全版本／状态字段，不复制原始响应、配置、节点秘密、凭据或私有路径。
- 区分本地 VPN 就绪与外部 HTTPS 观察：`LOCAL_READY / INTERNET_UNVERIFIED` 不是互联网可用承诺；外部观察带时间与过期边界，固定端点失败不能证明选中节点失败。
- 保留全部配置节点与选择；不新增启动 WAN 门禁，不自动重连、重启或切换节点。START／需重启核心的 RELOAD 不等待逐节点 TCP、TLS、HTTPS 探测；既有进程、同一 TUN、DNS、TLS、回滚与回执保护不删减。
