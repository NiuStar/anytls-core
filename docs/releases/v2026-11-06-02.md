# v2026-11-06-02：管理台观测信息与流量曲线修正

## 变更

- 管理台显示当前管理台进程的版本，并将磁盘安装版本作为独立信息；磁盘文件已更新不代表仍在运行的管理台进程已经更新。
- 流量曲线按实际观测跨度自适应显示，最长保留最近 24 小时；首次采样与尚未完成采样区间的实时速率只作临时观测，不冒充完整区间或累计历史。
- 保留真实零流量与缺测间隙的区别；不补造缺测流量，也不把未观测的时间填成零。
- 前端按现有 Go 流量合同收紧十进制大整数校验，避免非法数值或精度丢失造成错误流量显示。
- 实际网络丢包率尚未实现测量，明确显示“未测量”，不显示百分比；HTTPS 探测成功率或延迟不替代真实丢包率。

## 兼容与安装

本版仅修正管理台观测展示及其回归测试，不改变 TLS 校验、路由、上一版 IPv4-only/显式双栈策略、安装器、连接重试或 VPN 生命周期。

公开发行验收完成后，在 Mac 本机以普通用户执行（不要给整条命令加 sudo）：

```sh
curl -fsS https://raw.githubusercontent.com/NiuStar/anytls-core/main/get.sh | bash
```

保留现有节点、配置与应用密码。安装器沿用原策略：原 VPN 运行时安装成功后默认单次重连，原 VPN 停止时不自动启动；UNKNOWN/pending 不通过盲重试解除。该命令是用户自主安装入口，不是本次发布任务远程安装、更新正式助手或重启 VPN 的授权。

- 冻结功能候选已完成 Linux 标准内嵌全套 Go 测试，以及浏览器和真实 HTTP handler 回归；这些结果来自更新发行元数据之前的精确功能源码。
- 此说明为发布前证据快照。精确最终发行提交仍需 Mac arm64 隔离原生全套测试、vet、构建、版本与打包核验，以及 branch/main/tag 三平台 CI 和公开发行资产独立校验；本说明不作为这些门禁已完成的回执。
- 本次不远程安装、不接触正式服务控制 IPC、不重启 VPN；不声称用户正式 TUN、Chrome、外网网站或长期稳定性已验收。
