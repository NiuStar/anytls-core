## 已知拒绝不是未知结果恢复

typed HTTP 503 FAILED 只有在 strict ACK 完整、动作及阶段／原因配对有效、启动引用有效且清理／恢复／回执／job 观察全部安全时，才分类为已知拒绝（known rejected）。系统代理冲突显示中文原因，不能将任意 503 或 FAILED 当作可解锁证明。系统代理必须由用户自行决定，软件不静默关闭。

202、断连、超时、丢响应、无效 ACK、收尾不确定和部分应用仍保持 UNKNOWN 锁；不会自动 STOP／START，也不会凭普通 running 状态或辅助 trace 清锁。当前旧的内存 UNKNOWN 没有原始 ACK，安装新版本不能据此恢复或解锁。known rejected 不授权退出时盲发 STOP。

保留既有显式组件恢复事务的独立确认、身份校验和证据要求，不把该入口冒充旧内存 UNKNOWN 的通用恢复。当前 production 未修；发布本身不安装、不迁移用户组件、不启停 VPN，不承诺用户网络恢复。

## 连通性与夹具时钟

Connectivity 在读取边界依据 monotonic uptime 判断 45 秒新鲜性，MenuModel 对独立缓存的正向状态同步投影，避免延迟 timer 留下过期 online。timer 仅承担通知，不是新鲜性权威；getter 不产生生命周期重试。

产品参数保持 freshness 45 秒／请求 5 秒／失败后 15 秒／成功后 30 秒。自然过期夹具仅把固定 45.1 秒等待切换为与产品同源 uptime，保留原断言及外层限制，不等待到期望状态才通过。当前诊断已证 Date 与 uptime clock mismatch；历史未插桩的原 Date 失败根因仍 UNKNOWN，不能反推 NTP、VM 或 suspend。此前 r3 P2 handler capture 修复与原 HOLD 均保留。
