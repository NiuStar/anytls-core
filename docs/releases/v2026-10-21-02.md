# v2026-10-21-02 — 安装、重载、升级与本机控制台

## 新功能

- `anytls reload`：先预检当前磁盘配置，再自动 stop/start；切组后无需手动退出和启动。会短暂重连，不是无缝热更新。
- `anytls password`：查看本工具 WebUI 专用随机密码，固定用户名 `admin`；`password reset` 轮换并撤销旧会话。不读取 macOS 系统密码。
- `anytls webui`：默认 `http://127.0.0.1:18089`；本机登录、真实服务状态、节点／策略组、规则与原始 YAML 编辑、检查与安装升级。普通用户运行，系统操作由原生管理员窗口授权，网页不收系统密码。
- `anytls update --check` / `anytls update`：官方稳定源码 Release 更新，固定工具链、源归档 SHA256 校验、备份与原子替换，不覆盖配置。
- 一键源码安装脚本（macOS arm64），缺少精确 Go 时可在应用私有目录下载经官方 SHA 校验的工具链。
- 策略组局部 YAML 编辑保留未知字段、标量类型、注释和顺序；同值不写。运行时可保存下一次配置。

## 安装／使用

```sh
curl --fail --silent --show-error --proto '=https' --tlsv1.2 https://raw.githubusercontent.com/NiuStar/anytls-core/main/install.sh | bash -s -- --version v2026-10-21-02
# 已安装的新版本
anytls version
anytls password
anytls webui
# 浏览器打开 http://127.0.0.1:18089 ，用户名 admin
```

安装需要 Python 3 和网络获取精确依赖；不是预编译二进制包。可先下载审阅 install.sh 再运行。不要 sudo 运行 installer／WebUI。已有 `~/.anytls` 配置不覆盖；重装不自动停启 VPN。完成升级后用户主动 `reload`，正在运行的 WebUI 需退出重开。

## 验证与限制

- Mac 原生 166 顶层与 332 子测试 PASS，3 项 SKIP；vet/build 通过。安装器 24 项 Python UNIT 通过。
- 真实 Chromium 桌面及窄屏登录、策略组／配置保存、节点 no-op、退出通过。
- Mac 隔离目录首次安装／重装包含真实两次源码构建、版本读回、旧程序备份、命令链接与配置保留；该项使用受控 Release 响应，不是官方在线下载的证明。
- 冻结产品独立质量复审通过；先前 CI 的 Ubuntu TMPDIR 缺失已作为 workflow 环境问题修正，不修改已验产品代码。
- 本轮未执行正式特权 TUN 重载／管理员 GUI 弹窗，留给用户本机体验。reload 启动失败不承诺旧连接自动恢复；已有瞬时 DNS/TLS 故障不声称根治。
- 源码附件与 SHA256SUMS 不包含二进制，不是签名／Apple 公证；同 Release checksum 只代表 HTTPS 信任下的完整性。
- WebUI 仅 loopback HTTP，不要公网暴露；源码升级一旦接纳，关闭网页不取消安装，动作锁保持至安装 CLI 退出及版本核验。强杀／崩溃恢复不在本版保证范围。
