# v2026-10-22-02 — 32 MiB 订阅配置修复

配置上限由4 MiB统一提高到32 MiB，覆盖订阅及provider读取、转换输出、WebUI保存／导出、本地读取及服务快照。转换编码超限提供独立错误提示，不再误报格式无法识别；不通过规则去重、删减或重排压缩配置。普通控制请求仍保留16 KiB预算，完整配置JSON支持最坏六倍转义及信封开销。详见 `docs/config-size-limit.md`。

包含近期可信安装器修复：Intel缺ARM系统键兼容、系统授权终端独占、Bash／Zsh持久PATH配置、Python默认CA为空时本次安装选择系统CA。保持TLS校验；未知代理／私有CA仍需独立可信配置。

## 安装

```bash
curl -fsS https://raw.githubusercontent.com/NiuStar/anytls-core/main/get.sh | bash
```

以普通用户在Mac本机终端执行，不加sudo；按硬件选择Intel／Apple Silicon，默认最新稳定版。已有配置与密码保留，旧程序备份，WebUI安全切换；不会启动、停止或重载VPN。PATH在新终端生效，当前窗口可用 `~/.anytls/anytls-macos password`。
