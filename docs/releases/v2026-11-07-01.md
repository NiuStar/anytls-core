# v2026-11-07-01 — AnyTLS 0.4.0 无窗口菜单栏 App

## 下载与安装

这是首个公开菜单栏版本：发行标签 `v2026-11-07-01`，App 版本 `0.4.0`，build `0.4.0.20261107.2`。App 仅支持 **macOS 13+、Apple Silicon arm64**，没有 Intel App。下载本标签的 `anytls-core-v2026-11-07-01-menubar-darwin-arm64.zip`，解压、将 `AnyTLSMenuBar.app` 拖入「应用程序」并打开，从菜单选择「安装／更新组件…」，按需接受 macOS 原生管理员授权；App 流程不需要终端，首次安装不启动 VPN。签名为 **ad-hoc，未经 Developer ID 签名或公证**，不代表 Gatekeeper 已放行。

一个 App 携带同一 Go 核心与固定特权助手能力，复用 CLI／控制台／助手角色，没有第二个 VPN 引擎。无登录或连接设置窗口、不查询钥匙串；自动认证必须先匹配核心、助手及控制台身份，再通过匿名私有管道取得应用凭据。移除窗口不等于取消认证：后端 HTTP 登录、Origin／CSRF 和 helper UID 校验保留。后台失败仅更新红色菜单图标、菜单和提示，不激活 App、不弹模态窗口；显式安装、启动、停止、选节点及恢复仍可能显示必要确认。

原 CLI／WebUI 及 arm64、amd64 核心发行继续提供，终端安装入口不变（在 Mac 本机普通用户终端运行，不加 sudo）：

```sh
curl -fsS https://raw.githubusercontent.com/NiuStar/anytls-core/main/get.sh | bash
```

App 源码与核心对应源码使用同一发行标签，附件为 `anytls-core-v2026-11-07-01-corresponding-source.tar.gz`；保留 GPL、依赖许可证及 NOTICE。校验和是下载完整性检查，不是 Apple 身份签名。发布本身不安装、不替换现有服务、不启停用户 VPN。

## 从 0.3.1 或旧核心升级

先通过旧 App 正常退出并停止 VPN，再替换 App。新稳定标签使内嵌核心身份区别于候选，**不是只替换 App 就可直接用**；打开新 App 后仍须主动选择「安装／更新组件…」。规范 `~/.anytls/anytls-macos` 的旧 0700／0755 核心进入受控迁移，保留配置、选择、应用密码及相对 CA／规则。旧 `~/.anytls/anytls`、双文件布局、自定义目录、未知监听、身份或未决事务保持 HOLD，不强制覆盖。

迁移由包内 Go 独占一次 STOP、固定暂存助手授权与规范文件发布；App 不重复 STOP。已有手动／托管控制台必须证明所有权才能受控切换，不杀未知进程。App 更新后 VPN 保持停止，用户主动点击「恢复 VPN…」并即时确认后才启动；这与旧终端完整安装器默认重连原运行 VPN 的策略不同。中断或丢失回执保留持久 UNKNOWN／ARMED／ACTIVATION_UNKNOWN，不因重启 App 自动重发授权、STOP 或 START。

## 本次源码集成

- 菜单栏保留双行上传／下载、启动／停止／重连、启动节点、完整控制台与「退出并停止 VPN」。退出实现要求认证 STOP 成功清理回执及停止读回，然后仅结束自有控制台；失败或未知拒绝退出。**尚未据此证明正式 VPN 的路由／DNS 恢复，崩溃或强杀也不保证清理。**
- 初始组件准备、受控旧组件迁移及私有管道认证纳入 Go 核心。沿用既有 sing-box v1.14.3、严格 DoH／TLS、节点／默认组联动与后端认证，不放宽远端稳定发行下载验证。
- 本地构建可识别窄格式候选身份；更新检查仍只接受稳定远端标签、官方资产绑定及非 draft／prerelease。候选策略保留用于今后预试，不将候选标为稳定远端资产。
- 配套核心按 250ms 节奏观察／有界变化发布，App 每 250ms 读取，空闲心跳约 5 秒；只是采样与发布策略，不是 UI 即时、最低延迟或整机网卡流量承诺。单换 App 不提升旧核心采样。
- 本次发行准备仅修改版本、build 元数据及说明；冻结 Swift／Go／测试逻辑不变。沿用既有 bundle identity `org.anytls.menubar.candidate`，不因历史名称另换身份；当前 App 不使用钥匙串。
