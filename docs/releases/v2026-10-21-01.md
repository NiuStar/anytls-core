# v2026-10-21-01 — embedded core + startup retry

This is a fixed **source release**, not an Apple-signed application distribution.

## Changes
- Minimal embedded sing-box v1.14.3 registries; AnyTLS, mixed/TUN, direct, HTTPS/local DNS, gVisor and uTLS retained.
- Authenticated Box.Start cleanup-error patch and Python build wrapper.
- Shared CLI configuration compiler, service snapshot/CA/rules preservation and route/DNS restoration checks.
- HTTPS exit readiness: same endpoint, transient curl exit codes 6/7/28/35/52/56 only, at most three attempts with a shared 40-second context, route/service rechecks before retry. Certificate verification errors, invalid exit data and unknown failures do not retry.

## Limitations
No notarization/signing, kill-switch, automatic rule updates or exhaustive node/rule coverage. Skip-cert-verify connectivity is not TLS identity verification. Group YAML save is not lossless for comments, unknown group fields or numeric-looking unquoted strings. Full G3 measurement limitations remain in the historical stage closure document; historical failures are not erased.
