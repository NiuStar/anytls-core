## 保留的启动与配置语义

- START 与需要重新启动核心的 RELOAD 不逐节点查询路由，不等待节点 TCP、TLS 或 HTTPS 检测；全部配置节点保留，不按当前可达性裁剪，也不以当前选中节点的外部连通性作为启动门禁。静态规则出口、warm 节点、host exclusions 与自动物理接口策略保持。
- 完成只表示 `LOCAL_READY / INTERNET_UNVERIFIED`：本地核心进程、同一 TUN、DNS、配置编译及 TLS 策略、回执写入仍必须通过；不承诺互联网可用。节点连接 TLS 校验、显式风险确认、回滚与失败关闭不删除。
- baseline v2 恢复范围仍为 `LOCAL_INTERFACE_DNS`，保存公共物理接口与原始 DNS；诊断 schema 3 的 `node_route_verification=NOT_RUN` 不把未运行的节点路由检查写成已验证。旧 v0/v1 STOP 恢复仍按原节点路由范围核验。
- 链路失败仅建议用户手动切换节点；仍失败时检查本地网络。不自动切换节点、不自动重启，不将未知结果改为成功；保留配置与选择。
