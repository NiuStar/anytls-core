## 安装与替换

```bash
curl -fsS https://raw.githubusercontent.com/NiuStar/anytls-core/main/get.sh | bash
```

在 Mac 本机终端执行，不要给整条命令加 sudo。系统密码仅在本机系统授权提示中输入。官方入口按架构下载预编译程序和对应源码、核校验和并保留配置及旧程序备份；安装／程序更新本身不自动重启 VPN。正在运行的私有 VPN 快照仍是旧版本，须由用户在准备好短暂断网后受控重连。

## 验收及使用边界

- 最终提交的正式构建集成测试、三平台 CI、标签测试、双架构原生发行构建与公开附件核验是独立门，以其实际回执为准；前述候选测试不能替代它们。
- Intel 交叉构建已通过，但目标 Intel Mac 的真实 TUN 体验由用户另行验证；不宣称已定位或修复此前约 30 秒的 START_FAILED。
- Mac Studio 本轮 live TUN 使用原 argv，不覆盖新增 `-record-service` 或新版助手 `service-start` 控制链；连接记录启用仍需配套助手与新版 VPN。该试验结果不是 root authenticity、长期稳定或无丢失审计保证。
- 连接记录继续采用已批准的保守终态：CLOSED 只是最后保存状态，完整收尾与连续性 UNKNOWN；ROUTED 不等于认证／请求成功，DNS、REJECT、早期失败仍有覆盖缺口。
- SHA256SUMS 是 GitHub HTTPS 信任下的完整性校验，不是独立签名或 Apple 公证。
