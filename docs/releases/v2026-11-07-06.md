## 修复

旧控制台使用 `webui --port 18089 --listen 0.0.0.0` 时，菜单栏先前只接受相反顺序，错误显示“现有控制台身份或托管策略无法证明”。本版按固定参数键值对验证合法顺序，而非放宽进程身份。重复、缺失、未知、错误参数继续拒绝；托管参数仍须绑定精确 job label。PID、UID、出生时间、可执行路径、核心 SHA、agent-status、launchd/plist 策略和原始 argv 的后续身份比较保留。

App 已携带核心和固定助手能力，主动安装／更新组件只使用内嵌核心，不另从 GitHub 获取这些组件；系统管理员授权仍是必要步骤。
