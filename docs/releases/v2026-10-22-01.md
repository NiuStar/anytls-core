# v2026-10-22-01 — 32 MiB 配置与订阅转换修复

## 修复

- 配置上限由 4 MiB 统一提高到 32 MiB，覆盖订阅和 provider 获取、Clash 转换输出、WebUI 文件／粘贴／原始配置保存、导出及服务快照读取。
- 完整配置 JSON 请求容纳最多六倍转义并预留信封开销；普通控制请求仍限 16 KiB。
- 原文／编码结果超限返回独立的 `CONFIG_CONVERSION_TOO_LARGE`，不再把序列化超限误报成不支持 Clash Meta。既有 alias 展开工作量保护保留，具体边界见 `docs/config-size-limit.md`。
- 不通过规则去重、删减、重排或缩小缩进绕过限制。原有不支持协议／规则的跳过清单与显式确认不变。
- 包含可信安装入口的 Intel 系统键兼容、原生终端授权提示、Bash／Zsh PATH 自动配置及默认 CA 缺失时的进程内系统 CA 选择。

## 安装

在 Mac 本机终端以普通用户运行，不加 sudo：

```bash
curl -fsS https://raw.githubusercontent.com/NiuStar/anytls-core/main/get.sh | bash
```

默认取最新稳定版，按硬件选择 Intel 或 Apple Silicon。保留配置／密码和程序备份；安装自动切换 WebUI，但不停止、重载或启动 VPN。新终端直接可用 `anytls`；当前父终端 PATH 无法由子安装器修改，可用绝对路径 `~/.anytls/anytls-macos password`。
