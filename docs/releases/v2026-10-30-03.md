# v2026-10-30-03 — Web控制台静态传输与只读资源复用

## 变更

- 仅对四个固定公开内嵌资源（首页、app.js、startup.js、style.css）一次构建原始内容和Go标准库gzip表示，并发只读复用；不再每次请求复制完整内嵌文件。
- 根据全部Accept-Encoding字段、质量权重及显式拒绝选择原始/gzip；重复编码使用最低质量，gzip与identity同权时选gzip；均不可接受则406。无头或空头保持原始表示。
- 保留Cache-Control:no-store、MIME、安全响应头、Host/Origin、固定路径、GET-only及HEAD405；只增加表示相关的Vary/Content-Encoding/Content-Length。API、登录、配置、错误响应不压缩，不增加磁盘或敏感响应缓存。
- 页面、脚本、样式原始字节不变，解压后与原资源SHA一致。此前后台托管、更新重启及VPN/helper边界保持。

## 保持与限制

- no-store不变，因此只减少每次正文传输，不减少请求数或承诺浏览器长期缓存。固定只读资源最多四项，不随请求输入增长。
- 本版不修复另行记录的既有status轮询悬挂body、Shutdown错误处理问题，也不宣称Google IPv6或目标Intel网络故障已恢复。静态传输与VPN转发是不同边界。
- 后台更新自动重启仍需一次性用户级LaunchAgent托管；旧控制台或nohup不自动迁移。首次更新安装后，空闲退出旧控制台，保留原listen/port启用托管；仅重启WebUI，不更新helper、不重载VPN。安装期间禁止bootout/强杀，ExitTimeOut=0不保证外部卸载安全。
- 公网安装/正式TUN/Intel现场需用户测试；移动浏览器测试若使用viewport模拟须单列。校验和不等于Apple签名或公证。

## 更新

在Mac本机使用原安装入口，不对整条命令加sudo：

```sh
curl -fsS https://raw.githubusercontent.com/NiuStar/anytls-core/main/get.sh | bash
```

原安装入口可能按既有流程请求本机授权更新配套助手；普通网页更新/`anytls update`本身不替换root helper。已托管的新版控制台后续网页更新会按原校验/排空流程自动重启，可能需重新登录；只在认证读回目标内存版本后确认恢复。不要在安装未完成时重复更新或强制退出。

未托管时，请在空闲退出旧WebUI后，以普通GUI登录用户一次性执行（LAN用户保留原地址/端口）：

```sh
~/.anytls/anytls-macos webui install-agent --listen 127.0.0.1 --port 18089
~/.anytls/anytls-macos webui agent-status --listen 127.0.0.1 --port 18089
```

本次发布不执行目标机安装、助手替换、入口切换、LaunchAgent迁移或VPN启停。详见[静态传输测量报告](../static-transfer-report.md)和[托管操作说明](../webui-autorestart.md)。
