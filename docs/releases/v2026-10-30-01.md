# v2026-10-30-01 — 统一可信 DoH、规则管理与运行开销优化

## 主要变更

- TUN 接管范围内的 UDP／TCP 53 查询优先进入内建可信 DoH，不再依赖 GEOIP／RULE-SET 是否存在；无规则、DOMAIN／MATCH、解析器 IP DIRECT 等配置均保留固定 DNS 捕获前缀。
- 上游为 HTTPS `1.1.1.1`，严格验证 `cloudflare-dns.com`，通过全局选中节点 `anytls-out` 访问；DoH 失败不静默退回本地明文 DNS。DNS 节点不随每条业务 MATCH 策略组变化，业务分流保持原规则。
- 新增单条规则删除、确认与原始序号／ETag 保护；保留唯一最终 MATCH。规则列表支持完整已加载快照搜索、每页100条与原始序号跳转，不限制总规则量。
- 浏览列表不加载新增选项；显式新增仍校验有效选项。保存／读回失败显示中文不确定性提示，不自动重试。
- 减少 manifest 重复校验与 codec 字段元数据重复构建；缓存仅单次操作内使用，小对象保留原分配水平。YAML 投影复用一次语法树；记录定时小批提交不再立即重复发布状态，空闲心跳、Sync及恢复语义不变。

## DNS 覆盖与风险

- 仅保证进入本产品 TUN 路由覆盖范围的普通 DNS 接管，不是全机 kill-switch。排除地址／接口、局域网更具体路由、旧系统／浏览器缓存、应用自带 DoH／DoT、mDNS另列。
- 公共 DoH 可能无法解析企业内网名称并接收其查询；本版不暗加 split-DNS 或本地明文 fallback。有内网需求应先配置明确可信策略，不应盲目切换。
- DoH／基础节点不可用会使受管新查询失败，即使某些 DIRECT 业务链路仍可用。旧污染缓存不承诺即刻消失；未新增系统 DNS 改写、killall 或额外清缓存动作。
- 普通代理模式及低层无 DNS 配置兼容保留；停止／回滚仍使用既有保护与恢复警告。已知60秒观察晚轮时间轴仍可能标 GAP，未在本版扩展该codec。

## 更新与用户测试

公开发行后，在 Mac 本机使用原安装入口，不加 sudo：

```bash
curl -fsS https://raw.githubusercontent.com/NiuStar/anytls-core/main/get.sh | bash
```

安装器保留配置、选择和密码，备份旧程序，通过本机标准系统授权更新配套助手；不保存系统密码，不自动停止或重载 VPN。**普通 `anytls update`／网页程序更新不会替换 root helper**。TUN 服务核心也需由用户按维护窗口显式停止再启动，不能只更新网页便认定已用新核心。

更新后核对 `anytls version` 与 `anytls helper status` 的版本，用户自行安排重连，再验证系统 A／AAAA、UDP／TCP DNS、原网站严格TLS、实际业务出口和停止恢复。固定IP curl成功不等于程序DNS接管验收；不要永久写死 NodeSeek IP，不用 `-k`。

本次仅公开发行 macOS ARM64／Intel；保留原 Ubuntu＋Mac双架构 CI及Binary Release。未远程安装、更新现有助手或启停WebUI／VPN；172.16.51.184实际TUN及网站恢复待用户测试。校验和不是 Apple 签名／公证。
