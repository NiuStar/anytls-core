# v2026-10-28-01 — 启动就绪观察暂定60秒

## 行为变更

- launchd bootstrap 成功后，按60秒实际经过时间观察服务／TUN就绪，替代固定16轮。预检、编译、快照准备和 bootstrap 自身不消耗这个观察窗口；状态、路由工具和调度耗时计入。
- 到期不再开始新观察轮；同步探测跨期返回，不接受迟到就绪或开始新的 HTTPS 验证。工具自身不能被这个计时器强制中断，全部节点路由同步检查也可能跨期完成。
- 到期前已进入的 HTTPS 验证保留既有独立40秒预算、重试分类及最终身份检查。因此整个启动、同步工具和回滚不承诺60秒内完成。
- 仍须同次验证运行中的服务、真实 TUN 公共路由、所有节点的原物理旁路及 HTTPS；失败沿原路径回滚、恢复核验和清理，保留原因链。
- 不改变连接记录初始化／校验，不将本版描述为启动性能优化；TLS、DNS／路由政策、节点和 stop/start 恢复逻辑不变。

## 已知限制

现有启动时间轴 codec 只接受 START 的前16轮。较晚观察轮的辅助事件会被拒绝并明确标记 GAP，故晚轮详情可能缺失；不影响60秒观察状态机，也不伪称日志完整。本版不扩大该 schema 或事件存储预算。

## 更新与使用

正式发布完成后，在 Mac 本机终端运行默认最新版安装入口（不要加 sudo）：

```bash
curl -fsS https://raw.githubusercontent.com/NiuStar/anytls-core/main/get.sh | bash
```

安装器保留配置、选择和密码，备份旧程序，通过本机标准系统授权安装配套助手；不保存系统密码，不自动停止或重载 VPN。**普通 `anytls update`／网页程序更新不替换 root helper**，仅更新普通程序不足以让旧助手采用60秒窗口。更新完成后检查 `anytls version` 与 `anytls helper status`，再按自己的维护安排启动或重连。

本次仅公开发行 macOS ARM64／Intel，不远程安装、不更新现有助手、不切换 WebUI、不停启 VPN。原 Intel 体验由目标机另测；保留既定 Ubuntu＋Mac双架构 CI、Binary Release、Go1.27.3／SDK／依赖／补丁／wrapper／打包器／安装器。校验和不是 Apple 签名或公证。
