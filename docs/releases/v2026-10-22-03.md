# v2026-10-22-03 — 配置方案与节点延迟测试

## 变更

- 配置页支持保存磁盘当前配置为命名方案、独立复制方案、确认后切换。方案包含原始 YAML、启动选择和私有订阅元数据；不包含未保存编辑草稿，不打包引用的 CA／规则资源，不擅自选择节点。
- 切换先校验、备份与读回，再替换三项状态；失败回滚或明确报告恢复不确定。复用现有保存／自动应用链：停止时只保存，同值不重连；运行中应用可能短暂断网，保存成功但应用失败仍保留 pending。
- 编辑区复制带凭据警告；剪贴板失败明确提示手动复制，不伪报成功。
- 节点页支持单节点 TCP 建连延迟、真实 AnyTLS HTTPS 延迟及顺序批量／取消。固定 HTTPS 204 目标，目标证书严格校验；保留节点既有 TLS 策略及风险提示。网络期限 8 秒，同步核心构造／清理不是 OS 硬实时上限。不是 Mbps 带宽测试，不操作 TUN，不自动换节点。
- 配置／会话变化丢弃旧测试结果和迟到列表；策略组保存携带读取时 ETag，陈旧写入拒绝。修复真实 HTTP 验收发现的方案列表重复加锁问题。
- 将共享转换期限耗尽及取消分别显示为超时／取消，不再统称格式无效；32 MiB 上限、规则顺序及 TLS 语义不变。不声称这已确定先前用户订阅失败的唯一根因。

## 安装

```bash
curl -fsS https://raw.githubusercontent.com/NiuStar/anytls-core/main/get.sh | bash
```

Mac 本机普通用户终端执行，不加 sudo；按本机提示完成系统授权。既有配置和密码保留，旧程序备份，安装切换 WebUI 但不启动、停止或重载 VPN。持久 PATH 在新终端生效。
