## 公开安装与三种运行身份

普通用户程序／WebUI、root 特权助手、实际 VPN 核心必须分别核对，不能用页面版本替代另外两者。普通 CLI／网页 update 不替换 root 助手；助手 start 使用自身程序，再暂存 VPN 核心，因此只更新用户程序不能使旧助手启动新核心。

用户取得经验证的稳定发行后，在 **Mac 本机终端以普通用户**运行既有入口，不给整条命令加 sudo：

```bash
curl -fsS https://raw.githubusercontent.com/NiuStar/anytls-core/main/get.sh | bash
```

`get.sh` 入口拒绝 root；完整安装在助手阶段需要本机系统授权取得所需 root 权限，系统密码只在本机提示中输入，不发到聊天、不由工具保存。普通 update 与完整安装不是同一权限或更新范围。旧 `install-control-helper.sh` URL、`--version` 固定版本、`--check-download` 下载检查及显式 `--webui-listen` 等参数约定不变；完整安装默认最新稳定版，候选元数据不使本命令提前取得尚未发布的新版本。

安装默认仅下载当前硬件架构预编译包与 SHA256SUMS，不下载源码附件、不需要 Go、不本机编译；失败不退源码构建。保留配置、密码与旧程序备份。raw 下载失败时保留官方 API 回退、HTTPS／TLS 校验与超时；首次入口自身未取得时仍须按 [README](../../README.md#一键安装预编译程序--受限特权助手) 手动使用官方 API 备用命令。API 限流或 Release 下载故障可能阻断安装，不改 DNS／系统信任、不跳过 TLS。

完整安装更新助手但**不自动 reload 正在运行的 VPN**。用户完成安装后按自己的维护窗口显式 `anytls reload`／重连，再分别核对助手与实际核心身份，并验业务；安装助手不等于已经切换核心，重连也不是站点恢复保证。WebUI 更新／重启与 VPN 激活分开，见[托管说明](../webui-autorestart.md)和[助手权限](../privileged-helper.md)。默认 WebUI `0.0.0.0:18089`、mixed 代理 `0.0.0.0:11080` 不变；HTTP 明文、代理无入站认证，须限制网络暴露，Unix socket 不改网络服务。
