App **0.5.2**，build **0.5.2.20261110.1**，核心／发行标签 **`v2026-11-10-01`**；macOS 13+，Apple Silicon arm64 与 Intel amd64 独立原生包。

本说明冻结时尚未发布；附件名是发行约定，不是已经可下载的证明。通过最终提交的原生资格、原始 GitHub CI 与公开附件读回后才完成正式发布。Mac Studio 优先；操作员 Intel 本机手动验收延至发布后，未视为通过，GitHub Intel 原生 CI／打包仍须成功。

## 本版变化

- **启动不再同步等待外部检测站点。** 保留配置与 TLS 策略校验、进程、相同 TUN、全部服务器物理旁路、DNS、最终复核和恢复／清理保护；完成时明确标记 `LOCAL_READY / INTERNET_UNVERIFIED`，不是已经认证节点或验证外网。外网状态来自独立连通性观察或用户显式 HTTPS 检测，不倒填为此次启动证据。
- **普通受支持节点选择改为运行中热切换。** 预构建有限的不可变节点出口，通过私有认证控制通道进行代次／修订号匹配的原子选择，不为普通切换卸载服务或重建 TUN。新连接使用新节点，已有连接保留原出口；需要新出口的长连接由业务自行重新建立。
- 默认启动节点与直接默认 MATCH 选择组保持联动；固定节点规则和专用组不被覆盖。DNS 缓存按选择代次隔离，更新 DoH 连接池，旧查询不能填充新代次缓存；保留重复查询缓存。
- 连接记录按每个连接实际固定的出口归因；运行 JSON、Manifest、地址族策略与 DNS 身份绑定同一最终编译结果，不以当前选择重标旧连接。保留严格 TLS、证书和 IPv4-only 出口的受约束浏览器地址族行为。
- 选择仅变动以外的配置、节点凭据、证书、规则、来源身份变化或不具备热切能力时，明确提示 `RELOAD_REQUIRED`；不偷偷回退为完整停止／启动。不支持的组结构或未预热节点不报告热切成功。
- 切换确认不确定时显示 `SWITCH_UNKNOWN` 并阻止重复派发。仅使用原操作、代次、修订、节点及配置 ETag 绑定的认证 GET 只读恢复；普通刷新、NO_CHANGE、失效登录或迟到响应不能解锁。丢失原操作所有权时要求显式重新初始化／受控重连，不自动重放切换、STOP 或 reload。
- 新安装／重载事务显式使用回执 schema 2；历史严格回执继续按历史合同读取。当前安装器在写成功标记前检查成功结果版本及原 job 身份，缺失、别名、错误类型、未知版本和未决历史记录继续失败关闭。
- 保留上一版菜单不消失、最多 6 路节点 TCP 直连延迟测试和已完成结果缓存。测速不是带宽或代理可用性证明；物理接口直连测试仍只支持 IP 字面量，缺失安全路径返回 UNAVAILABLE，不回退 VPN 路由。
