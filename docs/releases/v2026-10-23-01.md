# v2026-10-23-01 — 连接记录与显式局域网控制台

**发布准备中。此文件存在不代表 Release 或安装包已公开。**

## 变更

- 连接记录页展示实际观察目标、顶层命中规则／规则集、同代策略组选择路径与实际出口；桌面紧凑列表、手机卡片、仅当前页搜索与筛选，技术身份详情可展开。
- 核心通过固定 SDK 的结构化 tracker 取得路由事件，真实 Rule 对象与本次编译 provenance 校验，不从当前磁盘配置推测旧记录，不解析日志字符串。
- root VPN 异步写私有历史，受限助手按授权 UID／配置命名空间只读分页。历史不设条数配额、不自动删除；队列／写盘失败显示 GAP，不阻塞 VPN 转发。
- 共享编解码严格拒绝重复／未知字段、无效身份与游标、已知丢失却无 GAP、未关闭却声称连续性正常等矛盾响应。
- 用户批准的保守终态：`CLOSED` 只表示最后保存的停止记录状态，不是全部同步、清理或日志完整性的证明。页面明确“完整收尾未验证／连续性 UNKNOWN”。原失败证据保留，最终修复验证结果另列。
- 新增显式私有 IPv4 监听：`anytls webui --listen <本机私有IPv4> --port 18089`。默认仍为回环；拒绝通配／公网地址，保留精确 Host／Origin、登录、CSRF 与无 CORS。HTTP 明文仅适合可信局域网。

## 更新与启用

官方安装入口在 Release 完成后可下载预编译 arm64／amd64 包，无需本机 Go：

```bash
curl -fsS https://raw.githubusercontent.com/NiuStar/anytls-core/main/get.sh | bash
```

网页／CLI 普通程序更新不更新 root 助手，也不自动重连 VPN。使用真实连接记录需要本机系统授权更新配套助手，并在准备好受控重连后让 VPN 运行新版核心。系统密码只在本机 sudo 提示中输入；不要发送到聊天或填写网页。

如果使用旧助手／旧 VPN，记录会如实显示不支持／不可用，而不是假空表。不要把安装完成、助手已注册或 ROUTED 观察当作真实网络健康证明。

## 能力边界

- 这不是完整逐连接审计：REJECT、DNS 劫持／内部 DNS、tracker 前错误不完全可见，DNS 状态 UNKNOWN；没有记录不代表没有流量。
- ROUTED 不等于已连接、认证成功、请求成功或真实拨号 peer 已确认；没有流量计数／持续时长／终结错误证明。
- 目标地址也是敏感历史。私有文件权限不是加密或安全擦除，root、备份和系统崩溃策略仍可能暴露它；退出网页不删除磁盘历史。
- SHA256SUMS 是共享 GitHub HTTPS 信任下的完整性校验，不是独立签名、Apple 签名或公证。
- 用户测试目标 `172.16.51.184` 尚未由此任务连接、安装或验收；不从地址推断 OS／架构。
- 实际 live TUN／root 安装与运行中采集须在目标机单独验证，不由原生回环／浏览器模拟验收替代。DIRECT 站点慢的用户原问题仍未定位。
