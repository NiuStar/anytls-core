# v2026-10-25-02 — WebUI IPv4 通配监听

## 变化

- 支持 `anytls webui --listen 0.0.0.0 --port 18089`，监听所有 IPv4 网卡；换网或修改本机 IP 后不必重新指定监听地址。
- 通配模式可通过实际 IP 或主机名访问，不需要逐台配置 Host 白名单；显式地址亦支持本机公网 IPv4。
- 同步调整安装器的进程识别、监听参数保留和就绪探测。通配监听的就绪请求使用具体回环地址，不把 `0.0.0.0` 当作访问 URL。
- 默认仍为 `127.0.0.1`；保留普通用户运行、应用登录、会话、精确同源 Origin、CSRF、无 CORS 和输入语法校验。非回环传输标识为 `network-http`，页面说明 HTTP 未加密。

## 安装与启动

使用仓库 README 的稳定预编译安装入口，安装器按本机架构选择 macOS arm64 或 amd64 程序包，不要求本机 Go。

```sh
curl -fsSL https://raw.githubusercontent.com/NiuStar/anytls-core/main/get.sh | bash
```

安装器默认保留已有 WebUI 的监听方式，不会把当前具体 IP 自动改成通配地址。需要通配监听时，在旧 WebUI 已退出、18089 空闲后，以普通用户运行：

```sh
~/.anytls/anytls-macos webui --listen 0.0.0.0 --port 18089
```

浏览器访问 `http://实际IP或主机名:18089/`；`0.0.0.0` 是绑定地址，不是应收藏的浏览器地址。

## 范围

本版只处理 WebUI 监听与对应安装器行为，不改变 AnyTLS 节点、证书验证、分流、TUN、DNS 或 IPv6 转发。本版不包含先前浏览器 IPv6/DNS 故障的修复，也不表示这些问题已解决。

发布不自动替换用户机器的程序，不重启现有 WebUI、助手、VPN 或 Clash。安装部署由用户执行；完整安装流程会进行本机系统授权和 WebUI 切换，VPN 不因该流程自动 reload。

实现及最终发行提交的测试、Mac 原生验收、三平台 CI、双架构打包和公开附件核验分别记录；本说明不将候选结果冒充正式部署。
