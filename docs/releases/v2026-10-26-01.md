## 安装

普通用户在 Mac 的本机终端使用稳定预编译入口（不要加 sudo）：

```sh
curl -fsS https://raw.githubusercontent.com/NiuStar/anytls-core/main/get.sh | bash
```

首次 raw 请求失败时可使用同仓库官方 API 入口，详见 README。一键安装自动按硬件选择 Apple Silicon／Intel 程序包，默认只下载程序包与 SHA256SUMS，不要求 Go。Release 另附精确应用源码与双架构对应源码／许可材料。下载摘要不是 Apple 签名或公证。

**公开发布本身不安装程序、不更新或重启助手、不重启 WebUI 或 VPN。** 用户执行完整安装会进行本机系统授权及 WebUI 切换，VPN 不自动 reload；已有正在运行的 VPN 不会因磁盘程序更新而自动加载新版代码。实际记录链需要匹配的新程序／助手及用户显式启动的新版 VPN，不能只凭网页版本或磁盘 SHA 认为已生效。

## 未关闭的问题

- 单次启动校验减少重复工作，不是所有启动卡顿或间歇失败的修复证明；同步记录 I/O 仍无 OS 级硬实时保证。
- 不宣称已经定位或修复用户测试机的空记录现场根因、Intel START_FAILED、DIRECT 域名／IP 白名单出口投诉，也不宣称正式 TUN／长期稳定性已通过。目标机体验由用户安装后测试。
- 不包含 TUN IPv6／DNS 修复。ROUTED 不是连接成功；DNS／REJECT／早期错误仍有记录覆盖缺口，不能把空页等同无流量。
