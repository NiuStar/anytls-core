# 下一版：安装、重载、升级与本机 WebUI

基线 c1d1118；开发分支 feat/operator-console。此为用户新增功能的实施范围；不改变 VPN 协议／DNS／分流语义，不恢复已停止的 inventory 工具支线。开发测试不自动授权正式部署。

## 命令与用户体验

- 一键安装：macOS arm64，安装至 ~/.anytls，配置只在不存在时创建，已有安装先备份；不自动停 VPN 或改全局代理。提供明确依赖检查和失败清理。当前 Release 只有源码，安装器必须诚实走源码构建或验证实际存在的二进制资产，不能假设存在下载包。
- reload：先用当前磁盘配置做无副作用预检；活动服务自动 stop→start，短暂断网；未运行时明确提示／按明确契约启动。预检失败保留现有服务；停止失败不继续启动。启动失败保持原恢复检查并清楚报告，不称无缝热切换。
- 配置允许活动期间修改下一次配置，不改变运行快照；UI 显示待重载。
- update：用户调用后检查官方仓库稳定 release，不下载任意 URL；安全版本名、HTTPS、精确源码 tag/commit、归档安全展开／checksum，源码版本需固定工具链与 wrapper 编译。保留程序备份、不覆盖配置；活动服务不暗自重启，新版本下次 reload 生效。检查和执行升级分开；自动升级指命令自动完成流程，不默认定时无人值守。
- password：输出本工具专用随机 WebUI 密码，固定账户 admin，不读取 macOS／Keychain／sudo 密码。凭据仅存应用私有目录0600；password reset 可轮换，旧会话失效。
- webui：默认 http://127.0.0.1:18089；明确禁止任意公网监听；内嵌静态文件，无 CDN。用户级运行，可通过原生授权提示调用严格白名单 root service 操作；WebUI 进程不以 root 提供 HTTP，不存 sudo 密码，不改 sudoers。

## Web 界面

中文轻量运营台，冷灰背景、深蓝导航与青蓝连接状态；系统字体和等宽运行信息。桌面导航+手机抽屉，主视图直接显示连接状态／运行版本／待重载。配置节点、各策略组选择、规则列表及原始 YAML 编辑（密码不在普通列表回显；显式配置编辑仅登录用户可访问）。启动／停止／重载／检查升级都有忙碌、完成、失败状态，不虚构连接指标。

## 安全／正确性

- 本机 Host 白名单（抗 DNS rebinding）、Origin 校验、随机 CSRF、HttpOnly SameSite=Strict 会话、登录尝试限速、会话到期；普通状态／静态响应不输出节点密码或管理密码。
- API 操作串行化；不把请求值拼入 shell。系统操作使用固定自身绝对路径＋固定命令及布尔授权，不提供任意命令执行。
- root 授权仅 macOS 原生提示；远程无 GUI／拒绝授权明确不可用，不绕过权限。
- 配置写入前实际解析并校验，保留同目录原子替换，编辑并发使用内容版本冲突拒绝；不调用任意证书路径写入，不自动增加 insecure。
- 新增服务命令、配置路径、凭据路径明确分离，service config 从原安装入口确定，不因 webui cwd 改变。

## 验证与交付顺序

1. reload +运行时选配置；命令回归和故障恢复测试。
2. password/session/Web API/嵌入页面；httptest 安全负例和浏览器桌面/窄屏实际交互。
3. install/update；用本地受控 HTTP/归档 fixtures 测试、不模拟为正式升级成功；Mac 临时安装目录原生安装/重装/配置保留验证。
4. 固定代码双审、Mac 原生 full tests/vet/build，隔离端口真实登录/配置/节点/代理；需要 root 的 TUN/reload 留本机授权，未执行不声称完成。
5. 更新文档提交推送；发布／覆盖正式入口单独说明。未完成二进制对应源码／许可证附件，不上传二进制 Release。
