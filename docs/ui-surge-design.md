# Surge 风格控制台优化

## 设计范围

当前产品是macOS本机AnyTLS控制台。参考Surge式网络工具的原生层级、侧栏与紧凑分组，保留AnyTLS自身标识，不复制商业品牌资产。将原有偏宣传页的大标题、宽松卡片改为操作优先的工作台；不增加虚构流量、延迟、速率或连通性。

- 浅灰侧栏、蓝色选中态、白色分组面板；系统字体、等宽版本／配置数据，较小而清晰的文字层级。
- 五个既有页面：概览、代理节点、策略组、配置与规则、版本更新。桌面固定侧栏、手机Drawer。
- 当前服务状态与网络健康严格分开；运行中不出现启动按钮，状态不明不提供冲突操作。
- 节点列表紧凑可搜索，策略组保持明确保存选择。原始配置读取仍显式提示密码风险。
- TLS跳验风险始终可发现，不恢复已取消勾选；认证／CSRF／If-Match／自动应用／失败反馈／no-op语义不改变。
- 不引入外部框架、CDN字体或远程资产。

## 已完成的浏览器验证

- 1440px桌面、390px和360px手机宽度，五页面共15个布局场景：无横向溢出，JS错误0。
- 节点搜索：名称匹配、零匹配提示、清空恢复均实测。
- 四类保存和服务按钮契约通过；8项保存成功／应用失败后刷新失败的反馈回归通过，TLS风险说明和无需勾选策略保持。
- 登录、错误密码清空、成功登录清空密码、退出、手机导航Escape关闭通过。
- 这些是Chromium实浏览器＋明确合成API的验证，不是Mac Safari或真实VPN重载验收。测试字体／动态库设置只影响隔离浏览器进程，不写入产品依赖。
- 生成的桌面及手机截图已保留。辅助视觉服务返回504，视觉审核标为`UNAVAILABLE`，不能以布局机器检查代替美学验收，也未因此重试或推进正式部署。
