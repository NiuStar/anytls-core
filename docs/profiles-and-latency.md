# 配置方案与节点延迟测试（候选规格）

## 配置方案

- 所有新接口复用既有精确 Host 校验和会话认证；每个 POST 均经过单一匹配 Origin 与 CSRF 校验，GET 列表同样需登录且不缓存。未通过这些门之前不得读写方案或产生测速网络活动。
- 保存当前已落盘配置为命名方案，不隐式保存编辑区草稿。在现有 actionMu 修改锁内一并捕获 YAML、选择、订阅三项并再次校验来源未变；并发控制台修改要么先完成、要么返回忙，不能捕获混合状态。外部 CLI／编辑器仍按既有乐观字节及身份复核，不宣称跨文件 OS 原子快照。可选选择／订阅不存在时明确保存其不存在状态，切换时清除目标相应的旧可选文件，不保留无关订阅。缺启动选择的方案可以保存，但不能假称已选节点；切换不擅自选节点，缺失时让用户选择后再启动。方案包括原始YAML字节、启动节点选择、私有订阅元数据；不复制或嵌入CA／本地规则文件，切换仍以当前配置目录解释引用，缺资源拒绝。
- 复制方案生成新的随机ID与名称，内容与来源快照保持独立。列表只返回ID、名称、创建时间和是否与当前配置一致，不返回密码或订阅令牌。尚不增加删除、同步、自动刷新。
- 切换需登录、CSRF、显式确认和当前配置If-Match；先校验，备份并读回，再一起替换配置／选择／订阅，失败回滚并复核，不确定则关闭后续操作的成功声明。
- 仍采用固定config.yaml路径，不重绑root助手。运行中通过现有finishConfigSave链自动应用，停止时只保存，不自行start。同值不重连；saved与applied分别报告。
- 方案保存在用户私有目录；文件0600、目录0700，随机ID和拒绝symlink／特殊文件，不能由名称构造路径。不声明能抵御恶意同UID父目录替换。
- 增加复制编辑区文本：含节点密码，必须明确用户操作，不写浏览器持久存储；剪贴板失败不得报告已复制。

## 节点测试

- 每节点可选TCP建连延迟或实际AnyTLS代理HTTPS延迟。TCP从本次精确节点建连前开始，到连接成功后结束并关闭连接，不证明认证／出口可用。HTTPS固定使用 `https://www.gstatic.com/generate_204`，从创建本次独立引擎／请求前开始，经精确节点的AnyTLS连接、认证及目标TLS，收到预期204响应并完成正文／连接清理后结束；禁重定向，非204或目标证书错误均为失败，不返回成功延迟。现有8秒期限覆盖上述网络与请求处理，调用结束必须清理本次引擎和连接；同步清理若超出期限需显式披露，不宣称OS硬实时保证。不是下载带宽Mbps或持续稳定性测试。
- 使用当前配置精确节点及现有CA优先级／显式skip-cert-verify选项。HTTPS测试不关闭目标证书校验，不接受任意目标URL。
- 无root、无TUN、无VPN停启／切换，不写选择和配置，不因测得更快而自动换节点。
- POST登录、CSRF、If-Match保护；8秒有界，错误只受控码。结果含mode/status/latency_ms/checked_at/config_etag，失败不伪造0ms。配置变化、退出及切换须丢弃过期结果。
- 批量按节点顺序执行并允许停止后续测试；限制并发以免干扰当前连接。页面清楚显示当前测试与失败状态。

## 接口

GET /api/v1/profiles -> profiles元数据、当前config etag。
POST /api/v1/profiles {name} -> 保存已落盘内容。
POST /api/v1/profiles/copy {id,name} -> 独立副本。
POST /api/v1/profiles/switch {id,confirm_replace:true,confirm_insecure:true} + If-Match ->标准saved/applied响应。
POST /api/v1/nodes/probe {name,mode:tcp|https,confirm_insecure:true} + If-Match ->延迟结果。
