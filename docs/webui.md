# WebUI

v2026-10-21-02 本机管理界面。源码版本与验证范围见 [版本说明](releases/v2026-10-21-02.md)。

```sh
anytls version
anytls password
anytls webui
# 浏览器打开 http://127.0.0.1:18089 ，用户名 admin
# 退出 WebUI：在启动它的终端按 Ctrl-C，不会因此停止 VPN。
```

可用 `anytls webui --port 18090` 更改端口；默认监听 `0.0.0.0`；其他设备使用 `http://主机实际IP:18089`。显式 `--listen 127.0.0.1` 可仅限本机；也可指定本机已分配的规范 IPv4。不要以 root/sudo 启动 WebUI。密码是本工具随机生成的专用凭据，并非 macOS 登录密码。保存位置为程序同目录 `webui.password`（0600），不要上传此文件；`anytls password reset` 轮换密码，旧登录会话失效。HTTP 不加密，网络访问会明文传输密码和会话；请通过防火墙限制来源或提供可信传输保护。不抵御恶意同 UID 进程。

## 操作

- 概览显示真实 launchd 状态；“服务进程运行”不等于网络已经连通，不虚构延迟或出口。
- 节点列表不显示密码；节点表单密码留空表示保持已有值。要显式查看／编辑完整 YAML，使用“配置”页的“读取私密配置”。
- 策略组的出口是**磁盘配置解析结果**，不是当前 root 运行快照。bootstrap/DNS 基座节点与业务策略组出口是不同选择。
- 节点／策略组／配置保存只改下一次配置，正在运行的 VPN 使用原快照。保存后点击“重新加载”才应用；会短暂断网，不是无缝热切换。
- 启动／停止／重新加载通过 macOS 原生管理员授权窗口完成。网页不接收系统密码，不修改 sudoers。SSH／无 GUI 环境、用户取消授权会明确失败。授权后服务还有独立配置和路由检查，不把授权成功当 VPN 成功。
- `reload` 未运行时要求先 start；预检失败不停止当前服务，停止失败不继续启动。启动阶段失败保留现有恢复检查，但不承诺恢复旧节点连接。
- 页面重开前不能可靠知道磁盘与 root 快照是否一致，显示“运行快照未确认”；不根据文件 mtime 猜测已生效。
- 配置编辑需要读取时的完整内容版本。如果同时有 CLI 或其他页面更改，返回冲突，需重新读取；WebUI 的动作锁不等于跨进程操作系统锁。

## 升级

检查升级仅查询官方稳定 Release。安装更新是主动源码构建，可能持续数分钟，旧程序先备份，不覆盖配置。**安装一旦开始，关闭网页／请求超时不视为取消；WebUI 持有动作锁直到安装子进程结束与新版本读回**，不得因网页断开再并发启动第二次升级。

升级只替换磁盘程序：VPN 要手动 reload，WebUI 终端要退出后重启才载入新代码；不自动停启。WebUI、CLI 或主机被外部强制终止时，不承诺崩溃恢复／跨进程锁；请检查命令退出与程序版本，不以“页面失败”推断原程序一定未变。

v2026-10-21-01 及更旧版本不含这些命令；需要安装 v2026-10-21-02 或更新版本。隔离测试的本地 Release 响应只能证明构建和安装逻辑，不能代替官方线上下载验证。
