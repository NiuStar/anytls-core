TLS 风险：跳过证书校验的节点可能遭受中间人攻击查看说明

导入配置

先预览，再备份并替换。运行中的 VPN 会自动重连。

自动识别 Clash / Mihomo YAML 并转换为 AnyTLS 配置，原生 YAML 不需转换。alias / merge 自动展开；HTTP provider 转为内联内容，缓存路径不会读取本机文件。不支持的协议或内容会跳过并列出清单，其余可用部分仍可导入；不会将其他协议节点改名为 AnyTLS。暂不支持 URI 或 Base64 订阅。

自动测速、故障切换等策略如需降为手动 select，会在预览中列出差异；导入时再明确确认。预览和导出均不会应用配置。

最大 32 MiB；服务器仍会校验大小与内容。选中文件优先于粘贴内容。

文件与粘贴导入默认保留已保存的订阅。

URL 可能含令牌，请勿在共享屏幕输入。仅在确认导入成功后保存；不会存入浏览器本地存储。
